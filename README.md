# Índices Unificados de Precios de la Construcción (INEI)

Consulta pública de los Índices Unificados del INEI, base diciembre 2025 = 100, para el reajuste de valorizaciones de obra pública mediante fórmula polinómica.

Último mes publicado: **2026-09** (R.J. N° 216-2026-INEI).

- `index.html`: calculadora Ir/Io, tabla del mes por área y descargas.
- `descargas/AAAA-MM/`: CSV (serie completa), Excel original del INEI, PDF de la R.J. y Excel de consulta.

Fuente: INEI y diario oficial El Peruano. Sitio no oficial; prevalece la R.J. publicada.
